تعلم HTML

لغة ترميز النص الفائق - الهيكل الأساسي لكل صفحة ويب

أساسيات HTML

ما هي HTML؟

HTML (HyperText Markup Language) ليست لغة برمجة، بل هي لغة ترميز تُستخدم لتحديد الهيكل والمحتوى الأساسي لصفحات الويب. تحدد مكان العناوين، الفقرات، الروابط، والجداول.

لماذا نتعلم HTML؟

HTML هي حجر الأساس لتطوير الويب. أي موقع أو تطبيق ويب يعتمد عليها. إتقانها ضروري لأي مطور ويب، حتى عند استخدام أطر عمل حديثة.

الهيكل الأساسي لصفحة HTML

تتبع جميع صفحات HTML هيكلًا قياسيًا يتكون من العناصر التالية:

  • : يحدد إصدار HTML المستخدم.
  • : العنصر الجذر الذي يحتوي على جميع محتوى الصفحة.
  • : معلومات وصفية عن الصفحة (عنوان، روابط CSS/JS).
  • : يحتوي على كل المحتوى المرئي للمستخدم.

تعلم CSS

Cascading Style Sheets - لغة تنسيق وتصميم صفحات الويب

أساسيات CSS

ما هي CSS؟

CSS (Cascading Style Sheets) هي لغة تُستخدم لوصف المظهر والتنسيق لمستندات HTML. بينما يوفر HTML الهيكل، فإن CSS يتحكم في الألوان، الخطوط، المسافات، التخطيط، وحتى الرسوم المتحركة.

لماذا نتعلم CSS؟

بدون CSS، ستكون جميع صفحات الويب مجرد نصوص سوداء على خلفية بيضاء. CSS هي ما يحول هذه الصفحات إلى تصاميم جذابة وحديثة وسهلة الاستخدام.

كيف تعمل CSS؟

تعمل CSS من خلال تحديد الأنماط لعناصر HTML. تتكون قاعدة CSS من ثلاثة أجزاء رئيسية:

  • المحدد (Selector): يحدد العنصر أو العناصر التي سيتم تطبيق النمط عليها (مثل h1 أو .class-name).
  • الخاصية (Property): سمة التنسيق التي تريد تغييرها (مثل color، font-size، margin).
  • القيمة (Value): القيمة المحددة للخاصية (مثل red، 16px، 20px).

التنسيق الأساسي

التحكم في الألوان، الخطوط، والمسافات الداخلية والخارجية للعناصر.

نموذج الصندوق (Box Model)

فهم margin، border، padding، وcontent هو أساس تصميم أي عنصر.

التخطيط الحديث

استخدام Flexbox وCSS Grid لإنشاء تخطيطات معقدة ومرنة بسهولة.

أمثلة عملية في CSS

p {

    text-align: justify;

نموذج الصندوق

التعامل مع الهوامش والحشوات والحدود.

/* إنشاء بطاقة محتوى */
.card {
    width: 300px;
    padding: 20px; /* المسافة الداخلية */
    margin: 20px auto; /* المسافة الخارجية */
    border: 2px solid #ddd; /* الإطار */
    border-radius: 12px; /* زوايا دائرية */
    background-color: #ffffff; /* لون الخلفية */
    box-shadow: 0 4px 8px rgba(0, 0, 0, 0.1); /* ظل */
    transition: transform 0.3s ease, box-shadow 0.3s ease;
}
/* تأثير عند تمرير الماوس */
.card:hover {
    transform: translateY(-5px);
    box-shadow: 0 8px 16px rgba(0, 0, 0, 0.2);

/* تنسيق الزر داخل البطاقة */
.card .button {
    display: inline-block;
    padding: 12px 24px;
    background-color: #4CAF50;
    color: white;
    text-decoration: none;
    border-radius: 6px;
    font-weight: bold;

.card .button:hover {

تخطيط Flexbox

إنشاء تخطيطات مرنة باستخدام Flexbox.

/* تخطيط مرن للأقسام */
.container {
    display: flex;
    justify-content: space-between; /* توزيع العناصر أفقياً */
    align-items: stretch; /* تمديد العناصر رأسياً */
    flex-wrap: wrap; /* السماح بالالتفاف إذا لم يكن هناك مساحة */
    gap: 20px; /* المسافة بين العناصر */
    padding: 20px;
}
/* تصميم كل عنصر داخل التخطيط */
.item {
    flex: 1 1 300px; /* يمكن التمدد والانكماش، الحد الأدنى للعرض 300px */
    padding: 20px;
    background-color: #fff;
    border-radius: 8px;
    box-shadow: 0 2px 5px rgba(0,0,0,0.1);
    text-align: center;
}
/* استجابة للشاشات الصغيرة */
@media (max-width: 768px) {
    .container {
        flex-direction: column; /* تغيير الاتجاه إلى عمودي */
        align-items: center; /* توسيط العناصر */
    }
    .item {
        width: 100%; /* اجعل العناصر بعرض كامل */
        max-width: 400px;
    }
}

تعلم JavaScript

لغة برمجة لجعل مواقعك تفاعلية

أساسيات JavaScript

ما هي JavaScript؟

JavaScript هي لغة برمجة عالية المستوى تُستخدم بشكل أساسي لجعل صفحات الويب تفاعلية. وهي واحدة من التقنيات الأساسية الثلاث (HTML, CSS, JS) لبناء الويب الحديث.

لماذا نتعلم JavaScript؟

JavaScript هي اللغة الأكثر استخدامًا في العالم لتطوير الويب. مع JavaScript يمكنك:

  • إضافة تفاعل إلى صفحات الويب (مثل النقرات، التمرير، إدخال البيانات).
  • إنشاء تطبيقات ويب ديناميكية لا تحتاج لإعادة تحميل الصفحة.
  • التحقق من صحة بيانات النماذج قبل إرسالها إلى الخادم.
  • إنشاء رسوم متحركة وتأثيرات بصرية.
  • التواصل مع واجهات برمجة التطبيقات (APIs) لجلب البيانات من مصادر خارجية.

إمكانيات JavaScript

تطورت JavaScript بشكل كبير وأصبحت تستخدم الآن في مجالات متعددة:

  • الواجهة الأمامية (Frontend): باستخدام أطر عمل مثل React, Vue, Angular.
  • الخلفية (Backend): باستخدام Node.js لبناء خوادم وتطبيقات كاملة.
  • تطبيقات الهاتف: باستخدام React Native أو Ionic.
  • تطبيقات سطح المكتب: باستخدام Electron.

المفاهيم الأساسية

المتغيرات، الدوال، الشروط، الحلقات، والمصفوفات هي حجر الأساس في أي برنامج.

نموذج كائن المستند (DOM)

القدرة على الوصول إلى عناصر HTML وتعديلها أو حذفها أو إضافة عناصر جديدة ديناميكيًا.

معالجة الأحداث

الاستجابة لأفعال المستخدم مثل النقر، الكتابة، التمرير، وغيرها.

الدوال والشروط

إنشاء دوال واستخدام الشروط للتحكم في سير البرنامج.

// دالة لحساب متوسط درجات الطالب
function calculateAverage(grades) {
    let sum = 0;
    for (let i = 0; i < grades.length; i++) {
        sum += grades[i];
    }
    return sum / grades.length;
}
// دالة لتحديد حالة الطالب بناءً على المعدل
function getStudentStatus(average) {
    if (average >= 90) {
        return "ممتاز";
    } else if (average >= 80) {
        return "جيد جداً";
    } else if (average >= 70) {
        return "جيد";
    } else {
        return "ضعيف";
    }
}
// استخدام الدوال
const studentGrades = [85, 92, 78, 96];
const avg = calculateAverage(studentGrades);
const status = getStudentStatus(avg);
console.log("المعدل: " + avg.toFixed(2));
console.log("الحالة: " + status);

التفاعل مع DOM

تعديل محتوى الصفحة واستجابة لأحداث المستخدم.

// تغيير نص عنصر عند النقر على زر
document.getElementById("changeTextBtn").addEventListener("click", function() {
    document.getElementById("targetText").textContent = "تم تغيير النص!";
    document.getElementById("targetText").style.color = "blue";
});
// إضافة عنصر جديد إلى القائمة
document.getElementById("addToListBtn").addEventListener("click", function() {
    const newItem = document.createElement("li");
    newItem.textContent = "عنصر جديد " + (document.querySelectorAll("#myList li").length + 1);
    document.getElementById("myList").appendChild(newItem);
});
// تغيير لون الخلفية عند تمرير الماوس فوق عنصر
document.getElementById("hoverBox").addEventListener("mouseenter", function() {
    this.style.backgroundColor = "#ffcc00";
});
document.getElementById("hoverBox").addEventListener("mouseleave", function() {
    this.style.backgroundColor = "#f0f0f0";
});

تعلم Python

لغة برمجة متعددة الاستخدامات وسهلة التعلم

أساسيات Python

ما هي Python؟

Python هي لغة برمجة عالية المستوى، سهلة التعلم وقوية. تتميز ببساطة تركيبها وسهولة قراءتها، مما يجعلها مثالية للمبتدئين والمحترفين على حد سواء. تُستخدم Python في مجالات متنوعة مثل تطوير الويب، تحليل البيانات، الذكاء الاصطناعي، الأتمتة، وغيرها الكثير.

لماذا نتعلم Python؟

Python هي واحدة من أكثر لغات البرمجة شعبية في العالم للأسباب التالية:

  • سهلة التعلم: تركيبها يشبه اللغة الإنجليزية، مما يقلل من منحنى التعلم.
  • متعددة الاستخدامات: تناسب تطوير الويب، تحليل البيانات، الذكاء الاصطناعي، الألعاب، والأتمتة.
  • مجتمع ضخم: ملايين المطورين حول العالم يقدمون الدعم والمكتبات المجانية.
  • مطلوبة في سوق العمل: من أكثر المهارات المطلوبة في مجالات التكنولوجيا.

مجالات استخدام Python

تستخدم Python في العديد من المجالات المهمة:

  • تطوير الويب: باستخدام أطر عمل مثل Django و Flask.
  • علم البيانات وتحليلها: باستخدام مكتبات مثل Pandas و NumPy و Matplotlib.
  • التعلم الآلي والذكاء الاصطناعي: باستخدام TensorFlow و PyTorch و Scikit-learn.
  • الأتمتة وبرمجة النصوص: لأتمتة المهام اليومية المتكررة.
  • تطوير تطبيقات سطح المكتب: باستخدام Tkinter أو PyQt.

المفاهيم الأساسية

المتغيرات، أنواع البيانات، الشروط، الحلقات، والدوال هي أساس البرمجة في Python.

هياكل البيانات

القوائم، القواميس، المجموعات، والصفوف لتخزين وإدارة البيانات بكفاءة.

البرمجة الكائنية

استخدام الكلاسات والكائنات لتنظيم الكود وجعله قابلاً لإعادة الاستخدام.
